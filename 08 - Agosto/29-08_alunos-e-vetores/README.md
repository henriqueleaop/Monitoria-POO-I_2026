# Monitoria de 29/08 — Alunos, médias e vetores

Turma de alunos com notas, média, situação e o aluno de maior média.

## Onde está o código

```text
src/Alunoz.java
src/Main.java
```

## Conceitos trabalhados

- **Vetor de objetos:** a turma é um vetor de `Alunoz`.
- **Métodos com responsabilidade única:** `calcularMedia`, `verificarSituacao`, `calcularMediaDaTurma`, `descobrirMaiorMedia` e `relatorio`.
- **Percorrer vetores:** acumular valores e encontrar o maior, inclusive em caso de empate.
- **`Scanner`:** entrada de dados pelo teclado.

## Para praticar

1. Faça uma busca de aluno pelo nome.
2. Mostre todos os alunos empatados com a maior média.

Abra a pasta no NetBeans (**File → Open Project**) e execute a classe que tem o método `main`.
